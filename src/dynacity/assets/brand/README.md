# DynaCITY brand

Official DynaCITY project logos, unchanged, from the project website
https://dynacity.eu/ (downloaded 2026-11-03):

- `dynacity-logo.webp` (398 × 100): navy wordmark, shown in the viewer header.
  https://dynacity.eu/wp-content/uploads/dynacity-logo.webp
- `favicon.webp` (512 × 512): the "D" mark, used as the page icon.
  https://dynacity.eu/wp-content/uploads/favicon.webp

`viewer.render_viewer` inlines them as data URIs, so an exported viewer stays a
single portable HTML file.
