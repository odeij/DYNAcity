# Viewer demo recordings

Captured from the local DYNAcity viewer on 20 October 2026. Both MP4 files
contain approximately 12 seconds of real browser capture, encoded as H.264
with browser-compatible pixel format and fast-start metadata. GIF previews
use the same captured frames at reduced resolution and frame rate.

- `traffic-simulation.mp4`: SUMO vehicle playback over historical hourly road
  speeds, with trip accounting and the simulation-speed indicator visible.
- `disaster-scenario.mp4`: an illustrative earthquake scenario, its animation,
  change from baseline and Monte Carlo KPI ranges.

The traffic is simulated, not live or measured GPS trajectories. Disaster
fragility and road-impact rules are uncalibrated assumptions. Basemap/data
attribution remains visible in the captures. Raw input data is not included.
