# Viewer demo recordings

Captured from the local DYNAcity viewer on 3 November 2026 (Charles Helou
Highway, 08:00 profile, bus routes hidden). The MP4 is about 8 seconds of real
browser capture at 1280x800, encoded as H.264. The viewer pauses playback while
SUMO catches up; those paused stretches were cut so the clip only shows moving
traffic. The GIF preview uses every second captured frame at reduced size.

- `traffic-simulation.mp4`: SUMO vehicle playback over historical hourly road
  speeds, with the Traffic panel and the 1x playback indicator visible.

The traffic is simulated, not live or measured GPS trajectories. Road-impact
rules are uncalibrated assumptions. Basemap/data
attribution remains visible in the captures. Raw input data is not included.
