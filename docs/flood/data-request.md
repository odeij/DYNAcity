# Draft data request — not sent

Subject: Existing Beirut stormwater and flood-modelling data for a documented neighborhood pilot

We are preparing a bounded Beirut flood-modelling pilot using DYNAcity and ANUGA. We seek existing survey/as-built files and observation records. The currently acquired neighborhood street-condition and ponding maps do not establish individual drain locations or a connected hydraulic network. No hydraulic event or catchment boundary has been selected from those maps alone.

Could you provide available GIS/CAD/as-built records and their metadata for:

- Stormwater inlets, catch basins, manholes, culverts and outfalls: stable asset IDs, surveyed locations, rim and invert levels, vertical datum and benchmarks, survey dates/accuracy, capture/outlet type and inspection/operational status.
- The connected pipe/channel network: upstream/downstream asset IDs, section shape and dimensions, material, slope/inverts, outfall connections, pumps/control structures, restrictions and event-date condition. Please distinguish built existing assets from proposed/conceptual designs and document any shared wastewater/stormwater connections.
- Bare-earth terrain and hydraulic structures: original DTM or classified ground points, native resolution, acquisition/processing history, nodata/coverage, vertical reference and independent checkpoints; surveyed kerbs, walls, openings, underpass floors and culvert connectivity. Please retain observed gaps rather than interpolate unknown structures.
- Dated storm forcing and boundaries: measured local rainfall time series with original accumulation intervals, timezone, units, gaps, flags and station/instrument metadata; measured coastal/river/outfall levels or discharges with their reference datum and uncertainty.
- Documented surface properties and initial state: infiltration/land-cover evidence, impervious areas, justified roughness derivations and observed initial water conditions. Please distinguish measurements from documented estimates; unsupported values should remain unknown.
- Independent flood observations for an identified event: measured depths/water-level records or high-water marks, timestamped wet/dry coverage, event imagery and timing, with coordinates, methods, uncertainty and relevant datum/ground reference. Calibration and independent validation observations will be kept separate.

Please include the spatial/temporal coverage, CRS/vertical datum, file version, whether the data describes existing or proposed conditions, known completeness limits, ownership and permitted local modelling/derivative sharing terms. We can accept the original native GIS/CAD, raster, point-cloud and observation formats; preserving the original source files is preferable to an undocumented conversion.

The pilot boundary will need contributing upstream area and downstream outlets, so any existing catchment delineation and its derivation would also be useful. If these records are held by a different office or consultant, please identify the data custodian and applicable access procedure.

Potential custodians/project leads, with verified supporting references, are listed in [data-inventory.md](data-inventory.md): Municipality of Beirut and its stormwater-plan consultants, CDR/implementing utilities and as-built consultants, and relevant terrain/rainfall/flood-observation custodians. No recipient has been selected and no message has been sent.
